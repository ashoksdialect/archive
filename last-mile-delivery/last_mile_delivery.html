Traffic Management

Global Routing - Amazon Route 53

The secure entry point for the delivery fleet, ensuring low-latency connectivity across geographic regions.

  • ▹
    Latency-Based Routing: Automatically directs mobile app traffic to the nearest healthy regional endpoint.
  • ▹
    High Availability: Health checks reroute traffic instantly if a regional API gateway fails.
  • ▹
    DNS-Level Security: Provides a hardened entry point for HTTPS requests into the private VPC.
Engineer's Note
Route 53 ensures we have zero single points of failure at the DNS level before data even reaches our servers.

Ingestion Spine

Stream Ingestion - Amazon Kinesis

Acting as the system's "shock absorber," handling millions of GPS pings without data loss.

  • ▹
    Order Preservation: Sharding by Courier ID ensures telemetry is processed in the exact sequence generated.
  • ▹
    Decoupled Architecture: Buffers spikes in field activity so they don't overwhelm downstream databases.
  • ▹
    Parallel Consumption: Simultaneously feeds Lambda for logic and S3 for long-term archival.
Engineer's Note
Kinesis is critical for decoupling our real-time fleet activity from our persistence layer.

Acceleration Layer

In-Memory Speed - ElastiCache Redis

A protective shield for our databases, storing "hot" data and courier sessions in-memory to prevent bottlenecks.

  • ▹
    Database Offloading: Absorbs the massive volume of read requests that would otherwise crush Aurora.
  • ▹
    Real-time State: Manages volatile courier status updates with sub-millisecond response times.
  • ▹
    Distributed Locking: Prevents "Double Dispatching" by ensuring synchronized order state.
Engineer's Note
Caching isn't optional at this scale; it's the only way to keep our 10M+ delivery state fast.

Data Lake

Ground Truth - Amazon S3

Our immutable archival layer, providing a landing zone for every GPS ping and status update for future analysis.

  • ▹
    Parquet Optimization: Stores archived events in compressed formats to slash storage costs.
  • ▹
    11 Nines Durability: Guaranteed zero data loss for years of historical delivery telemetry.
  • ▹
    Athena Integration: Enables direct SQL queries over raw logs without ingestion overhead.
Engineer's Note
If our operational databases ever fail, we can rebuild the entire system state from these logs.

Decoupling analytical workloads from our production path to analyze billions of rows of historical data.
